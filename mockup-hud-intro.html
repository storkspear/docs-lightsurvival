키트 카탈로그 — hud.js 부품 전부

이 절은 산출물이 아니라 참고 자료입니다 — 나머지 넷 (강화·상점·도감·출격일지)은 다른 손이 이 키트 위에 얹으므로, 그 손이 여기를 보고 부품을 그대로 가져다 쓸 수 있어야 합니다. 참조(짙은 남색 + 시안 얇은 선 + 동심원 레이더 + 각진 프레임 + 눈금 고리 + 점선 궤도 + 막대 그래프 + 스캔라인)를 뜯어 일곱 갈래로 나눴습니다. 접두는 전부 hud/HUD — vfx.js(5만 줄+)의 어느 이름과도 안 겹치게 확인했습니다.

⑤ 스캔라인 · 격자 — .hudgrid · .hudscan · .hudvig

배경 결 셋은 캔버스가 아니라 CSS 입니다 — 이 저장소의 오랜 병목이 GPU 채우기라(「화려함의 비용은 개수가 아니라 픽셀 면적」), 화면 전체를 매 프레임 캔버스로 덮는 대신 GPU 합성 레이어에 맡깁니다. hud.js 가 로드되는 순간 스타일시트로 심어지므로 아래처럼 세 div 만 겹치면 됩니다.

⑥ 등장 애니메이션 — hudOpenLoop(u,opt)

선이 그어지고(line) → 면이 차고(fill) → 내용이 뜹니다(content). 실제 화면전환에는 u 에 단조증가값 (Math.min(1,(t-t0)/dur))을 넘겨 한 번만 재생합니다 — 여기서는 「보여주기 위해」 3초 주기로 되풀이합니다. 아래 값 셋이 u=0 과 u=1 에서 항상 0 이라(패널이 완전히 꺼진 상태) 되풀이해도 이음매가 없습니다 — 검증은 이음매 검증 절입니다.

line/fill/content 진행값을 화면에 그대로 찍었습니다

⑦ 허브 레일 — hudRail(hostId,cur,tabs?)

여섯 화면이 같이 쓰는 좌측 탭 여섯 칸입니다. 정본은 vfx.js 의 LBRAIL/FLWGLYPH 그대로 읽습니다 — 이 함수는 둘레만 냉광으로 새로 입힙니다. ⭐ 2026-08-27 에 여섯째 칸 「강화」가 상점 밑에 섰습니다 — 스탯 강화가 상점을 떠나며 최상위 목적지가 됐습니다(근거는 LBRAIL 머리). ⇒ 레일에 없는 화면이 없어졌고 tabs 인자는 앞으로 다른 구성을 보여야 할 장이 생길 때만 씁니다.
